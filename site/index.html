What you are seeing

One simulation state is rendered twice, once for each display size. Rendering never feeds back into the state. All floating-point in the simulation path goes through muse-softfloat; the browser build is the same core compiled to WebAssembly and is checked against pinned native/board hashes during deployment.

The physical kits add touch, IMU, clock, battery and storage. This page is the screen emulator used while those drivers are built.
